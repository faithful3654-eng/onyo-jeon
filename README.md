## 업데이트

1. 기존 프로그램의 검은 콘솔 창에서 Ctrl+C로 종료합니다.
2. 새 ZIP의 SH_Auto_Seller 폴더 내용 전체를 기존 프로그램 폴더에 덮어씁니다. ZIP에는 data, .env, .venv가 없어 기존 자료를 보존합니다. 먼저 DB 백업을 권장합니다.
3. START_WINDOWS.bat 실행 후 브라우저에서 Ctrl+F5로 새로고침합니다.
4. 새 **일일 추천 메일** 메뉴를 엽니다.
5. 본인의 네이버 계정(발신·수신 동일)과 허용된 SMTP 인증정보를 Windows 화면에서만 입력합니다. 비밀번호를 채팅/GitHub/메모로 보내지 마세요.
6. **연결 설정 저장 → 본인 계정으로 테스트 메일 → 공개자료 조사 미리보기 → 자동발송 승인 → 일일 메일 예약 켜기** 순서로 진행합니다.

## 기본 조건

- 한국시간 매일 **오전 9시 조사 시작**, 완료 후 메일 발송. PC가 켜져 있고 해당 Windows 사용자로 로그인돼 있어야 합니다. 웹 관리자 화면은 계속 열어두지 않아도 됩니다.
- 한국 발송 확인 상품 최대 10개. 성인용품·주류·생물 제외. 부족하면 부족 개수와 사유를 표시합니다.
- 리뷰 수·의미 불명확한 내부 숫자를 판매량으로 사용하지 않습니다. 판매지표/기간 미공개는 **인기 목록 참고 후보 / 판매량 미확인**입니다.
- 원가·광고비 등이 부족하므로 **수익성 추가 검증 필요**입니다. 광고 후 공헌이익률 25%나 판매 성공을 보장하지 않습니다.
- 국내 소싱은 사용자 상품마스터의 동일 이름 후보가 있을 때만 참고 링크를 연결합니다. 동일 규격/도매 조건은 추가 확인해야 하며, 한국 쇼핑몰 전체 자동 검색은 아직 미연결입니다.

## 실제 연결 전 확인

메일 인증과 Windows 예약을 완료하기 전에는 자동 발송이 **활성화되지 않습니다**. 테스트 메일 성공 및 최근 조사 미리보기의 한국 발송 후보 1개 이상 확인 후에만 예약 버튼을 켤 수 있습니다. 활성화 후에도 접근/사이트 구조가 바뀌면 부족 사유 또는 후보 0개를 보고할 수 있습니다.

Windows 인증정보는 사용자별 DPAPI로 암호화해 로컬에 보관합니다. SQLite/DB 백업/내보내기에 비밀번호를 넣지 않습니다. 하루 한 번 일일 발송을 시도하며 전송 결과가 불명확하면 자동 재전송하지 않습니다. 계정·폴더를 변경하기 전 원래 예약을 해제하세요.
